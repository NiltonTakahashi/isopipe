# ISO-PIPE · Isométrico de Tubulação

App de desenho isométrico de tubulação com cálculo de espessura mínima (ASME B31.3) e registro de medições de espessura. Funciona no navegador e pode ser instalado em tablets e celulares Android, inclusive para uso sem internet.

Como instalar no Android: abra o endereço do GitHub Pages deste repositório no Chrome e toque em **⬇ Instalar app** (ou menu ⋮ → Instalar app). Detalhes em `LEIA-ME.txt`.
